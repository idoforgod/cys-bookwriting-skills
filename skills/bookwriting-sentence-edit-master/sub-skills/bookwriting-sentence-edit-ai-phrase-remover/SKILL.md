# bookwriting-sentence-edit-ai-phrase-remover ⭐ (Step 3 · AI 말투 제거)

저자가 가장 싫어하는 것이다. 아래 다섯 유형을 **감지 단서로 찾고**, 바꾸고, **다시 훑는다.**

| # | 유형 | 감지 단서 | 바꾸는 법 |
|---|---|---|---|
| 1 | 극적 연출·장면 묘사 | 현재형 장면 도입(「앉아 …을 펼친다」), 「다름 아닌 ○○ 스스로가」 | 과거형 사실 서술: 언제·누가·무엇을 |
| 2 | 단타·웅변조 반복 | 다섯 어절 이하 문장의 연속, 「한쪽에는 … 다른 쪽에는 …」 대구 | 앞뒤 문장과 합치고 대구는 사실만 남긴다 |
| 3 | 메타 문장 | 「앞 절에서 필자가」, 「이 절은 셋을 정한다」, 「여기서 가져갈 것은」 | 삭제. 필요하면 「여기서는 세 가지를 제시하려 한다」로 담백하게 |
| 4 | 자문자답·수사 의문문 | 「어찌 된 일인가?」, 「무슨 뜻인가.」, 문단 안 의문문 2개 이상 | 삭제하고 결론을 바로 쓴다. 문단 전환용 질문만 한 번 허용 |
| 5 | 어색한 조어·추상어 | 일상에서 쓰지 않는 명사구(「틀린 자리」, 「한계선」, 「유보를 감당하는 목소리」) | 일상적인 말로 풀어 쓴다 |

## 판정 원칙
- 원고의 **원래 구조**(「첫째, 둘째, 셋째」)는 연출이 아니다. 지우지 않는다.
- 인용문 안의 표현은 저자의 문장이 아니므로 고치지 않는다.
- 유형이 애매하면 **뜻을 그대로 두는 쪽**으로 고친다 — 지우기보다 평범하게 풀기를 우선한다.

## 자기검증(바꾼 뒤 반드시)
- [ ] 다섯 유형의 감지 단서로 결과물을 **다시 훑어** 잔존 0
- [ ] 문단 안 의문문 2개 이상인 곳 0
- [ ] 다섯 어절 이하 문장이 세 번 이상 연달아 나오는 곳 0
- [ ] 지운 문장이 담고 있던 **사실**이 다른 문장으로 살아 있는가
