# bookwriting-sentence-edit-context-reader (Step 1 · 편집 기준표)

## 하는 일
원고와 대화 맥락에서 아래 다섯 항목을 읽어 **편집 기준표**를 만든다. 기준표는 사용자에게 보이지 않는 내부 메모이고, Step 2~7 이 모두 이것을 기준으로 판단한다.

| 항목 | 읽는 법 | 예 |
|---|---|---|
| 분야·장르 | 다루는 주제와 서술 방식 | 경제·경영 / 인문 / 과학 / 실용 / 에세이 |
| 대상 독자 | 용어 수준, 설명의 친절함 | 입문자 / 실무자 / 전문가 / 일반 독자 |
| 관점 | 저자가 일관되게 서 있는 자리 | 학문적 / 종교적 / 실무적 / 비판적 |
| 어미·문체 | 문장 끝 | ~다 체 / ~습니다 체 / 혼용 여부 |
| 인용 관행 | 각주 표기·인용 판본·출처 형식 | 위첨자 각주 / 괄호 출처 / 특정 번역본 |

## 판단 순서
1. **원고 자체**에서 읽는다 — 가장 강한 근거다.
2. 원고만으로 모호하면 **이전 대화와 저자가 준 지침**을 따른다.
3. 그래도 모호한 항목이 **결과를 바꾸는 경우에만** 한 번 묻는다. 어미처럼 원고에서 확인되는 것은 묻지 않는다.

## 자기검증
- [ ] 다섯 항목이 모두 채워졌는가(모르면 「원고 기준 유지」로 적고 추측하지 않는다)
- [ ] 어미가 원고 안에서 혼용되면, 다수 어미를 기준으로 하고 혼용 위치를 확인 사항에 넘긴다
- [ ] 관점을 저자 대신 새로 정하지 않았는가 — 관점은 읽는 것이지 부여하는 것이 아니다
