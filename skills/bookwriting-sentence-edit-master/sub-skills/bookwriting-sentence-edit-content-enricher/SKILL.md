# bookwriting-sentence-edit-content-enricher (Step 5 · 보강)

## 보강 대상
- 인물·개념의 **이름이 빠진 곳**(「한 분석가」 → 실명이 원고나 출처에 있으면 채운다)
- 사례의 **빈 칸**(누가·언제·무엇을·어떻게·결과 중 빠진 것)
- **대상 독자가 바로 써먹을 구체적 예시**(확인할 항목, 질문 예시, 적용 절차) — 기준표의 독자 수준에 맞춘다

## 각주 규칙(가장 엄격하다)
| 상황 | 처리 |
|---|---|
| 보강 내용이 **기존 각주의 출처 범위 안** | 기존 번호를 그대로 쓴다 |
| **새 출처**가 필요 | 번호를 달지 않는다 → 확인 사항에 「각주 필요: (위치)」 |
| 출처가 있는지 **확실하지 않다** | 보강하지 않는다 → 확인 사항으로 넘긴다 |

번호를 새로 끼우면 뒤 번호가 전부 밀린다. 그래서 새 번호는 **절대** 만들지 않는다.

## 사실 규칙
- 확실하지 않은 사실은 지어내지 않는다. 필요하면 웹 검색으로 확인하고, 확인한 것만 쓴다.
- 확인했으나 원고와 다르면 본문을 바꾸지 않고 확인 사항에 적는다(원고 수치는 저자의 것이다).

## 흐름 규칙
- 보강은 **본문 흐름 안에 녹인다.** 【추가】 같은 표시, 소제목, 별도 박스를 만들지 않는다.

## 자기검증
- [ ] 새로 만든 각주 번호 0
- [ ] 보강한 문장마다 근거가 「원고 / 기존 각주 / 웹 확인」 중 하나로 말해지는가
- [ ] 「각주 필요」 위치를 빠짐없이 확인 사항에 넘겼는가
