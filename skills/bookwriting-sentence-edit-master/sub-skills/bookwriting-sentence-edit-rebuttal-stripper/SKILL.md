# bookwriting-sentence-edit-rebuttal-stripper ⭐ (Step 4 · 자기반박 제거)

## 왜 따로 두는가
저자는 「반론을 넣으라」는 지시 때문에 글이 엉망이 된 경험이 있다. 자기반박은 AI 말투와 달리 **논리 구조**에 박혀 있어서, 문장 단위로 고치면 남는다. 그래서 문단 단위로 따로 본다.

## 걷어 낼 것
- **자기반박 문장**: 「이 말을 그대로 받으면 곧바로 무너진다」, 「이 문장은 절반만 맞다」, 「결말이 나왔으니 확정된 사실로 다시 적는다」, 「여기까지가 한계다」, 「필자의 말버릇 하나를 고쳐야 한다」
- **반증 나열 문단**: 반증 조건·반대 근거를 늘어놓는 문단은 통째로 뺀다.
- **판정 문장**: 「이 사건은 조언의 근거가 아니라 한계선이다」처럼 글이 자기 주장의 지위를 스스로 깎는 문장.

## 남길 것 — 반박과 보충을 가르는 기준
| 반박(뺀다) | 보충(남긴다) |
|---|---|
| 앞의 주장을 **무너뜨린다** | 앞의 주장의 **적용 범위를 밝힌다** |
| 「그대로 받으면 틀린다」 | 「이는 평균에 대한 이야기다. 실제로는 …」 |
| 글이 자신을 의심한다 | 독자에게 가려 읽는 법을 알려 준다 |

## 바꾸는 틀
- 「다만 ○○를 그대로 따르기보다는 가려서 받아들일 줄 알아야 한다.」
- 「이는 전체 평균에 대한 이야기다. 실제로는 …」
- 인용 원전(경전·고전·법령·선행 연구)의 해석 단서: 「본래 뜻은 이것이다. 그러나 이 내용은 오늘의 독자에게도 시사점을 준다.」

## 자기검증
- [ ] 결과물에 자기반박 문장 0
- [ ] 뺀 문단 바로 앞뒤 문장이 자연스럽게 이어지는가(끊긴 연결 0)
- [ ] 보충으로 바꾼 단서가 원래 주장을 뒤집지 않는가
