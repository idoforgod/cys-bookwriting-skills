# bookwriting-sentence-edit-style-aligner (Step 2 · 목표 문체 정렬)

## 문장
- 한 문장에는 한 가지 내용만 담는다. 쉼표로 세 덩어리 이상 이어지면 나눈다.
- 문장 길이는 중간으로 고르게 한다. 아주 짧은 문장이 연달아 나오면 합치고, 한 문장이 원고 평균의 두 배를 넘으면 나눈다.
- 어미는 기준표의 문체를 따르고, 바꾸지 않는다.

## 문단
- **사실 → 근거(수치·연구·사례) → 의미 → 독자에게 주는 시사점** 순서로 짠다.
- 연구·사례는 **누가, 언제, 무엇을, 어떻게, 결과** 순서로 소개한다. 빠진 칸이 있으면 content-enricher 가 채우거나 확인 사항으로 넘긴다.

## 연결어
- '그러나', '반면', '따라서', '이때', '한편', '그렇다고' 같은 평범한 말을 쓴다.
- '바로 그때', '놀랍게도', '그런데 여기서' 같은 연출형 연결어는 평범한 말로 바꾼다.

## 용어 풀이
- 어려운 용어는 **처음 나올 때 한 번** 기준표의 독자 수준에 맞춰 풀어 준다. 두 번째부터는 풀지 않는다.
- 전문가 독자 대상이면 업계 표준 용어는 풀지 않는다.

## 자기검증
- [ ] 바꾼 문장이 원문과 같은 사실을 말하는가(뜻이 달라진 곳 0)
- [ ] 같은 용어를 두 번 이상 풀지 않았는가
- [ ] 어미가 기준표와 다른 문장 0
