# bookwriting-sentence-edit-manuscript-guard ⭐ (Step 6 · 원고 불변 검사)

다듬기는 문장을 바꾸지만 **원고의 뼈대는 바꾸지 않는다.** 이 단계는 그것을 눈대중이 아니라 **목록 대조**로 확인한다.

## 대조 절차
1. **원본**에서 아래 목록을 뽑는다.
2. **결과물**에서 같은 목록을 뽑는다.
3. 두 목록을 나란히 놓고 비교한다. 어긋난 항목은 **결과물 쪽을 원본대로 되돌린다.**

| 불변 요소 | 뽑는 법 | 통과 조건 |
|---|---|---|
| 각주 번호열 | 위첨자 번호를 등장 순서대로(⁵⁸, ⁷²~⁷⁹ 등) | 순서·개수·위치(같은 문장 끝) 동일 |
| 표 | [표 n] 번호, 각 표의 행·열 내용, 표 아래 '기준'·'읽는 법'·'출처' 주석 | 번호·내용·주석 동일(배열 정리만 허용) |
| 수치·연도·인명 | 숫자, 연도, 고유명사 | 하나도 바뀌지 않음 |
| 장·절 참조 | 「4절에서」, 「6장에서」 | 전부 존속 |
| 직접 인용 | 따옴표·인용 블록 안 문장, 출처 표기 | 글자 그대로, 출처 형식 원고와 동일 |
| 원래 구조 | 「첫째·둘째·셋째」 같은 열거 | 존속 |
| 넣지 말 것 | 소제목, 【추가】, 변경 라벨 | 결과물에 0 |
| 비공개 체계 | 저자의 내부 방법론·사내 프로세스의 구체 구조 | 결과물에 드러나지 않음 |

## 사실이 틀려 보일 때
원고의 수치·연도·인명이 사실과 다르다고 보여도 **본문을 고치지 않는다.** 그대로 두거나 중립적으로 다듬고, 확인 사항에 「사실 확인: (위치) — (의심 근거)」로 넘긴다.

## 자기검증(통과해야 출력으로 간다)
- [ ] 각주 번호열 원본 == 결과물
- [ ] 표 번호 목록 원본 == 결과물
- [ ] 수치·연도·인명 차이 0
- [ ] 장·절 참조 누락 0
- [ ] 금지 표시(소제목·【추가】·라벨) 0
하나라도 실패하면 해당 부분을 원본대로 되돌린 뒤 다시 검사한다.
