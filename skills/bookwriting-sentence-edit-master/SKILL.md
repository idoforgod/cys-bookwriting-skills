# bookwriting-sentence-edit-master (최종 다듬기 마스터)

사용자는 책을 쓰고 있다. 원고를 붙여 넣으면 아래 7단계를 차례로 수행해, 사람이 쓴 것처럼 자연스럽게 읽히는 글로 다듬는다. 각 단계의 세부 규칙과 자기검증은 하위 스킬에 있다. 마스터는 **순서와 불변 원칙**만 쥔다.

## 7단계와 하위 스킬

| Step | 하위 스킬 | 하는 일 |
|---|---|---|
| 1 | `bookwriting-sentence-edit-context-reader` | 분야·장르·독자·관점·어미·인용 관행을 읽어 **편집 기준표** 고정 |
| 2 | `bookwriting-sentence-edit-style-aligner` | 한 문장 한 내용, 사실→근거→의미→시사점 문단, 독자 눈높이 용어 풀이 |
| 3 | `bookwriting-sentence-edit-ai-phrase-remover` ⭐ | AI식 표현 5유형을 감지 단서로 찾아 평범한 설명문으로 · 잔존 재검사 |
| 4 | `bookwriting-sentence-edit-rebuttal-stripper` ⭐ | 자기반박·반증 나열 제거, 필요한 단서는 「보충」으로 전환 |
| 5 | `bookwriting-sentence-edit-content-enricher` | 빠진 이름·사례 칸·독자용 예시 보강 · 새 각주 번호 금지 |
| 6 | `bookwriting-sentence-edit-manuscript-guard` ⭐ | 각주 번호열·표·수치·인명·참조·인용을 **원본과 목록 대조** · 어긋나면 되돌림 |
| 7 | `bookwriting-sentence-edit-output-packager` | 본문만 담은 .md 파일 + 대화창 3칸 보고 |

## 흐름

```
원고 수신
 → context-reader (편집 기준표)
 → style-aligner → ai-phrase-remover ⭐ → rebuttal-stripper ⭐ → content-enricher
 → manuscript-guard ⭐ ── 실패 시 해당 부분을 원본대로 되돌리고 재검사
 → output-packager (파일 + 3칸 보고)
```

Step 6 을 통과하지 못한 결과물은 출력하지 않는다.

## 불변 원칙 (모든 단계에 걸린다)

1. **각주 번호를 새로 매기거나 빼지 않는다.** 새 출처가 필요하면 「각주 필요」로 넘긴다.
2. **원고의 수치·연도·인명은 바꾸지 않는다.** 틀려 보이면 확인 사항으로 넘긴다.
3. **사실을 지어내지 않는다.** 확실하지 않으면 웹으로 확인하거나 넘긴다.
4. **본문에 소제목·【추가】·변경 라벨을 넣지 않는다.**
5. **관점과 어미는 저자의 것이다.** 읽고 따르되 새로 정하지 않는다.

## 고친 예시

**고치기 전**
> 한 분석가가 책상 앞에 앉아 공개된 자료를 펼쳐 놓고 계산을 시작한다. … 그는 이 계산을 감독 기관에 가져갔다. 한 번이 아니었다.

**고친 뒤**
> 2000년, 업계에서 일하던 한 분석가는 공개된 자료를 검토하다가 이상한 점을 발견했다. … 그는 이 분석 결과를 감독 기관에 제출했고, 이후 8년 동안 여러 차례 문제를 제기했다.

**고치기 전**
> 정확도는 정보량과 관계없이 평균적으로 같았다. … 어찌 된 일인가? 결국 정보를 더 받는다고 판단이 나아지는 것은 아니라는 뜻이다.

**고친 뒤**
> 그 결과 정보의 양과 관계없이 평균 예측 정확도는 거의 같았다. … 정보가 늘어도 판단의 정확도는 나아지지 않았고, 확신만 커진 것이다.

**고치기 전**
> 이 장이 옮겨 오는 것은 그 대상이 아니라, 자료와 판독법을 다 갖추고도 자기가 선 자리에는 쓰지 않는다는 그 상태다.

**고친 뒤**
> 그러나 이 내용은 오늘의 독자에게도 시사점을 준다. 자료를 충분히 갖추고 읽는 법도 알면서, 정작 자신이 처한 상황에는 그 분별력을 적용하지 못하는 경우가 많기 때문이다.
